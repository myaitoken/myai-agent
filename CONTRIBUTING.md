# Contributing

Thanks for considering a contribution to a MyAi project.

## Quick start

1. Fork, branch from main, commit small focused changes.
2. Open a PR against main describing motivation and any linked issue.

## Rules

- One change per PR.
- Keep tests green; add tests for new features.
- No secrets in commits - use .env.example placeholders.

## Security

Email security@myaitoken.io for vulnerabilities instead of a public issue.
